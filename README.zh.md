# AT 进度看板

*(English README: [README.md](README.md))*

一个记录 Appalachian Trail 徒步进度的静态网站：记下你走过的路段，在地图上看它们变成洋红色，按州查看进度。没有账号，没有服务器，所有数据都留在你的浏览器里。

## 能做什么

- 地图上显示整条 AT，里程数据来自官方步道数据。
- 按日期、起点、终点录入一段徒步——输入里程数或地名都行。
- 重复走过或有重叠的路段不会重复计算。
- 总里程、完成百分比、徒步天数，以及按州拆分的进度。
- 把记录导出/导入成 JSON 文件，用来备份或换设备。
- 中英文、英里/公里，页面顶部随时切换。

## 怎么用

双击 [`start.command`](start.command)——它会启动本地服务器并自动打开浏览器。第一次运行，macOS 会提示"来自未标识的开发者"，去系统设置 → 隐私与安全性，点"仍要打开"。

地图需要一个免费的 Mapbox token。第一次打开页面会提示你输入，去 [account.mapbox.com](https://account.mapbox.com) 免费注册一个，粘贴进去就行，只会记在这台设备的浏览器里。

徒步记录存在浏览器里。换设备或换浏览器之前，先点"导出 JSON"；到了新的地方，用"导入 JSON"把记录带回来。

## 想部署自己的版本

纯静态网站，不需要构建步骤：fork 这个仓库，推到你自己的 GitHub，在仓库设置里打开 Pages 就行。数据流水线、目录结构、数据格式和许可信息，都写在 [SPEC.md](SPEC.md) 里。
